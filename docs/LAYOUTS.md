# Layouts

Every layout in every view, in dark and light. Switch layouts in Settings > Appearance. The same section has the Dock position, Layout icon and Icons options.

## Layouts

- **original**: The default layout: a left sidebar next to the main panels, Geist type, and the default palette. Palette: default palette.
- **dense**: One step denser everywhere: more tree rows, table rows and log lines per screen. Structure and icons are unchanged. Palette: default palette.
- **calm**: Slower reading pace: larger type and controls, no brand row, and spacing instead of rules. Icons are unchanged. Palette: default palette.
- **material**: A friendlier desktop look: filled Material glyphs, rounder controls, a labelled nav with pill items and pill tabs. Palette: default palette.
- **blueprint**: A drafting sheet in navy (dark) or blue-white paper (light). Every division is a thin drawn line, panes and tabs are square, and panel heads, tabs and status are mono annotations. Palette: own palette (`blueprint`).
- **transit**: Wayfinding signage. Nav and headings use a condensed sans, and each screen has its own line colour for the nav marker, tab-row rule, active tab and primary actions. Palette: own palette (`transit`).
- **islands**: Each pane is a flat island on a darker frame, with gutters between them. The dark theme is green-grey, with no shadows or gradients. Palette: own palette (`islands`).
- **modeline**: A terminal-native look. All type is mono, dividers are box-drawing rules, nothing has a radius, and a vim-style modeline leads the status bar. Dark is a deep teal with an ochre accent. Palette: own palette (`modeline`).
- **ribbon**: An app-suite look. The main menu moves to a header strip of labelled screen tabs and there is no sidebar, so content gets the full width. Palette: default palette.
- **ledger**: Printed ledger paper. Light-first, with hairline rules, small uppercase column heads, tabular figures, and a masthead header with text menu words instead of a sidebar. Palette: own palette (`ledger`).
- **atlas**: Files-first. Coloured Atom icons and a labelled nav grouped into sections, with the global tools at the right end of a full-width status row. A quiet cool grey palette with a teal accent. Palette: own palette (`atlas`).
